# 动态报告展示回归契约

这套门禁用于防止修复表格时丢失图表、修复图表时破坏历史报告等交叉回退。

## 自动覆盖矩阵

| 场景 | 必须保持的结果 |
|---|---|
| 标准 Markdown 表格 | 转为真实表格，并保留图形分析入口 |
| 历史 Markdown 表格 | 缺失分隔行时自动恢复；CRLF 内容同样有效 |
| 旧原生 HTML 表格 | 安全清洗后继续使用现有表格与图表能力 |
| HTML 中的管道表文本 | 恢复为真实表格，不展示 `|---|` 原文 |
| 宽表与长说明 | 桌面自适应，手机端在卡片内横向滚动，工具栏不被推出 |
| 多表报告 | 每张表可独立分析，同时保留多数据集对比入口 |
| 业务标识 | `000155`、`070200046604` 等前导零不丢失 |
| 空值与异常值 | `/`、`-`、`N/A`、`null`、百分比保持可读，不误转数值 |
| 涨跌语义 | 上涨/正收益红色，下跌/负收益绿色，零值灰色，只作用于方向性指标 |
| 报告层级 | 标题、段落、列表、引用、链接、行内代码和代码块均保留 |
| 内部元数据 | `doc://...`、`records[1…2]` 不出现在页面，且不吞掉相邻换行 |
| 证据链 | 默认折叠，灰色小字号，能够展开查看 |
| 图表类型 | 折线图、柱状图、饼图、散点图、指标卡、组合面板全部渲染 |
| 图表交互 | 图表、表格、原始数据三种视图可切换且数据不丢失 |
| 安全边界 | script、iframe、object、embed、form、事件属性和 javascript URL 被移除 |
| 响应式布局 | 1366px 桌面与 390px 手机均不产生整页横向溢出 |

## 执行方式

```bash
npm run test:ui-artifact
npm run test:ui-artifact:visual
npm run verify:ui-artifact
```

真实浏览器测试会生成：

- `test-results/ui-artifact-regression-desktop.png`
- `test-results/ui-artifact-regression-mobile.png`

修改 Markdown 清理、HTML 清洗、表格增强、证据样式、图表组件或聊天历史展示入口时，必须执行 `npm run verify:ui-artifact`。
