OpenSearch、Silo、Redis 启动维护命令
在部署服务器 192.168.195.221 上执行，使用 root 或具有 Docker 权限的账号。
以下命令管理现有容器，沿用已有数据和配置。停止或重启会中断对应服务。

OpenSearch（容器：opensearch-node）
启动：
  docker start opensearch-node
停止：
  docker stop -t 60 opensearch-node
重启：
  docker restart -t 60 opensearch-node
检查运行及健康状态：
  docker inspect --format '{{json .State}}' opensearch-node
查看最近日志：
  docker logs --tail 100 --timestamps opensearch-node
实时跟踪日志（Ctrl+C 只退出日志查看）：
  docker logs -f --tail 100 opensearch-node
查看 CPU、内存等资源占用：
  docker stats --no-stream opensearch-node
查看端口映射：
  docker port opensearch-node
核对数据与配置挂载：
  docker inspect --format '{{json .Mounts}}' opensearch-node
核对自动重启策略：
  docker inspect --format '{{json .HostConfig.RestartPolicy}}' opensearch-node

三个服务统一检查：
  docker ps -a --filter name=opensearch-node --filter name=silo --filter name=redis
仅在需要恢复三个已停止服务时统一启动：
  docker start opensearch-node silo redis

日常启动无需 docker pull，也无需删除或重建容器。
升级前先备份并核对镜像 digest、挂载与原配置；docker pull 不会自动更新现有容器。
现有容器被删除后，docker start 无法恢复它；需按服务器私密容器快照恢复完整创建参数。
实际数据挂载记录见 docs/opensearch、docs/silo、docs/redis 下的 mounts.json。
