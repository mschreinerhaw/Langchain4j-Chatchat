Silo、OpenSearch、PostgreSQL：完整创建及外置目录说明
以下依据当前运行容器 docker inspect 生成，供容器被删除后的恢复/重建使用。
现有容器日常启动仍使用 docker start；重建时才需要下面的 docker run。
本次只编写脚本和保存恢复配置，没有停止、重命名或重建运行中的服务。
创建脚本不会自动停止或删除已有容器；同名容器存在时会拒绝执行。
不要让新旧数据库或对象存储实例同时读写同一数据目录。


===== Silo =====
Silo 完整重建命令（包含外置目录）
镜像：pgsty/silo@sha256:08ce1505b5eacefbad1ca07159b242b9ce045a11c2817e3bc257b25f77bbc02d

当前实际外置挂载：
/opt/runtime-os-docker-stage/config/silo/app-policy.json -> /bootstrap/app-policy.json（只读）
/opt/runtime-os-docker-stage/silo/data -> /data（读写）
/opt/runtime-os-docker-stage/silo/secrets -> /run/secrets（只读）

环境变量文件（包含现用凭据，权限 0600，不进入文档包）：/opt/runtime-os/standard-maintenance-20261115/private/rebuild/silo.env
使用 --mount，宿主机目录不存在时直接失败，避免自动生成空数据目录。
同名容器存在时不要直接运行创建命令；先在维护窗口关闭原实例并核实数据备份。
可执行脚本：bash /opt/runtime-os/standard-maintenance-20261115/rebuild/create-silo.sh

完整命令：
docker \
+  run \
+  -d \
+  --name \
+  "$CONTAINER_NAME" \
+  --restart \
+  unless-stopped \
+  --network \
+  runtime-os-app-stage_control \
+  --env-file \
+  /opt/runtime-os/standard-maintenance-20261115/private/rebuild/silo.env \
+  --workdir \
+  / \
+  --memory \
+  1073741824 \
+  --cpus \
+  2.0 \
+  --shm-size \
+  67108864 \
+  --security-opt \
+  no-new-privileges:true \
+  --publish \
+  127.0.0.1:9000:9000/tcp \
+  --publish \
+  127.0.0.1:9001:9001/tcp \
+  --mount \
+  type=bind,src=/opt/runtime-os-docker-stage/config/silo/app-policy.json,dst=/bootstrap/app-policy.json,readonly \
+  --mount \
+  type=bind,src=/opt/runtime-os-docker-stage/silo/data,dst=/data \
+  --mount \
+  type=bind,src=/opt/runtime-os-docker-stage/silo/secrets,dst=/run/secrets,readonly \
+  pgsty/silo@sha256:08ce1505b5eacefbad1ca07159b242b9ce045a11c2817e3bc257b25f77bbc02d \
+  server \
+  /data \
+  --console-address \
+  :9001

创建后检查：

docker inspect --format '{{json .State}}' silo

当前实际外置挂载：

/data/opensearch/logs -> /usr/share/opensearch/logs（读写）
/data/opensearch/plugins -> /usr/share/opensearch/plugins（读写）

当前三个外置挂载是 data、logs、plugins；原容器没有外置 config。
配置及 TLS 证书已从当前容器导出并保留文件属主，恢复副本位于：/opt/runtime-os/standard-maintenance-20261115/private/rebuild/opensearch-config
以下重建命令额外挂载该恢复目录到 /usr/share/opensearch/config，避免重建后丢失现用配置/证书。

环境变量文件（包含现用凭据，权限 0600，不进入文档包）：/opt/runtime-os/standard-maintenance-20261115/private/rebuild/opensearch-node.env
使用 --mount，宿主机目录不存在时直接失败，避免自动生成空数据目录。
同名容器存在时不要直接运行创建命令；先在维护窗口关闭原实例并核实数据备份。
可执行脚本：bash /opt/runtime-os/standard-maintenance-20261115/rebuild/create-opensearch-node.sh

完整命令：
docker \
+  run \
+  -d \
+  --name \
+  "$CONTAINER_NAME" \
+  --restart \
+  unless-stopped \
+  --network \
+  bridge \
+  --env-file \
+  /opt/runtime-os/standard-maintenance-20261115/private/rebuild/opensearch-node.env \
+  --user \
+  1000 \
+  --workdir \
+  /usr/share/opensearch \
+  --shm-size \
+  67108864 \
+  --publish \
+  9200:9200/tcp \
+  --publish \
+  9600:9600/tcp \
+  --mount \
+  type=bind,src=/data/opensearch/data,dst=/usr/share/opensearch/data \
+  --mount \
+  type=bind,src=/data/opensearch/logs,dst=/usr/share/opensearch/logs \
+  --mount \
+  type=bind,src=/data/opensearch/plugins,dst=/usr/share/opensearch/plugins \
+  --mount \
+  type=bind,src=/opt/runtime-os/standard-maintenance-20261115/private/rebuild/opensearch-config,dst=/usr/share/opensearch/config \
+  opensearchproject/opensearch@sha256:72fe2fc84be8295906b8efca020b46c58ed45c8da60cd9b8b49e1991e38e89a4 \
+  opensearch

创建后检查：

docker inspect --format '{{json .State}}' opensearch-node
