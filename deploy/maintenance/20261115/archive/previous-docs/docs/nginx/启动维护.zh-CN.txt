镜像标签：nginx:1.28-alpine

查看配置（可能包含私密环境变量，仅限管理员本机查看）：
  docker compose -p runtime-os-stage-maintenance --env-file /opt/runtime-os-docker-stage/config/deployment.env -f /opt/runtime-os-docker-stage/compose.gateway-ui.json config -q
启动：
  docker compose -p runtime-os-stage-maintenance --env-file /opt/runtime-os-docker-stage/config/deployment.env -f /opt/runtime-os-docker-stage/compose.gateway-ui.json up -d --no-deps gateway
停止：
  docker compose -p runtime-os-stage-maintenance --env-file /opt/runtime-os-docker-stage/config/deployment.env -f /opt/runtime-os-docker-stage/compose.gateway-ui.json stop gateway
重启：
  docker compose -p runtime-os-stage-maintenance --env-file /opt/runtime-os-docker-stage/config/deployment.env -f /opt/runtime-os-docker-stage/compose.gateway-ui.json restart gateway
更新配置或镜像后重建容器：
  docker compose -p runtime-os-stage-maintenance --env-file /opt/runtime-os-docker-stage/config/deployment.env -f /opt/runtime-os-docker-stage/compose.gateway-ui.json up -d --no-deps --force-recreate gateway
查看日志：
  docker compose -p runtime-os-stage-maintenance --env-file /opt/runtime-os-docker-stage/config/deployment.env -f /opt/runtime-os-docker-stage/compose.gateway-ui.json logs --tail 100 gateway

持久化挂载及网络由上述 Compose 文件维护。只修改镜像版本不改变原有数据目录。
不要执行 down -v，也不要删除数据库卷、Silo 对象数据和聊天正文目录。
升级顺序：先备份，再拉取/构建，再修改 Compose 中已审核的 digest，重建并验证。
回退：恢复 private 目录中的原配置和原镜像；数据库模式变更需要单独审核，不能通过镜像降级代替数据库恢复。

构建/安装说明：使用上游已发布镜像，不编译第三方数据库源码。
  docker pull nginx:1.28-alpine
  docker image inspect nginx:1.28-alpine
将实际 RepoDigest 固定到 Compose；拉取标签不会自动升级当前固定 digest。
