镜像构建与升级说明：nginx
实际镜像 ID、digest、挂载与运行命令见同目录启动维护文档。
构建/安装说明：使用上游已发布镜像，不编译第三方数据库源码。
  docker pull nginx:1.28-alpine
  docker image inspect nginx:1.28-alpine
将实际 RepoDigest 固定到 Compose；拉取标签不会自动升级当前固定 digest。

业务端口 18100，关联 MCP 端口 18101。
配置：/opt/runtime-os-docker-stage/config/public-gateway.conf
前端静态目录：/opt/runtime-os/releases/latest-main-20261115/public-ui；监控静态目录：/opt/runtime-os/releases/latest-main-20261115/source/chatchat-api/src/main/resources/coding-monitor。
验证：docker exec runtime-os-app-stage-gateway-1 nginx -t
