当前实际外置挂载：
998a12dcec518fdb8a7201c81cbd3d507cae16d6e817851638a9d2cbadd3adf5 -> /var/lib/postgresql（读写）
/data/postgresql/18/docker -> /var/lib/postgresql/18/docker（读写）

外层 /var/lib/postgresql 的既有 Docker 卷也保留；不能用空新卷替换。
常规维护推荐：docker compose -f /opt/runtime-os/standard-maintenance-20261115/infrastructure.compose.json up -d postgresql

环境变量文件（包含现用凭据，权限 0600，不进入文档包）：/opt/runtime-os/standard-maintenance-20261115/private/rebuild/postgresql18.env
使用 --mount，宿主机目录不存在时直接失败，避免自动生成空数据目录。
同名容器存在时不要直接运行创建命令；先在维护窗口关闭原实例并核实数据备份。
可执行脚本：bash /opt/runtime-os/standard-maintenance-20261115/rebuild/create-postgresql18.sh

完整命令：
docker \
+  run \
+  -d \
+  --name \
+  "$CONTAINER_NAME" \
+  --restart \
+  unless-stopped \
+  --network \
+  bridge \
+  --env-file \
+  /opt/runtime-os/standard-maintenance-20261115/private/rebuild/postgresql18.env \
+  --shm-size \
+  67108864 \
+  --publish \
+  5432:5432/tcp \
+  --mount \
+  type=volume,src=998a12dcec518fdb8a7201c81cbd3d507cae16d6e817851638a9d2cbadd3adf5,dst=/var/lib/postgresql \
+  --mount \
+  type=bind,src=/data/postgresql/18/docker,dst=/var/lib/postgresql/18/docker \
+  --health-cmd \
+  'pg_isready -U "${POSTGRES_USER}"' \
+  --health-interval \
+  5000000000ns \
+  --health-timeout \
+  5000000000ns \
+  --health-retries \
+  30 \
+  postgres@sha256:e3d24f6906d0760bf4da0dae872415391ededefad23fd471c47dc53b0ddf3c42 \
+  postgres
