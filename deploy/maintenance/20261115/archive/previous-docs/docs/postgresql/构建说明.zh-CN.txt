镜像构建与升级说明：postgresql
实际镜像 ID、digest、挂载与运行命令见同目录启动维护文档。
构建/安装说明：使用上游已发布镜像，不编译第三方数据库源码。
  docker pull postgres:18.6
  docker image inspect postgres:18.6
将实际 RepoDigest 固定到 Compose；拉取标签不会自动升级当前固定 digest。

数据目录：/data/postgresql/18/docker，容器 PGDATA 保持同一路径。外层原 Docker 卷也保留。
密码文件：private/postgres.env（权限 0600）。
备份：docker exec postgresql18 pg_dumpall -U postgres > /受控备份目录/all.sql
健康检查：docker exec postgresql18 pg_isready -U postgres
跨主版本升级必须 pg_upgrade 或导出导入，不直接替换主版本标签。
