日常状态检查与排障命令
Redis（容器：redis）
启动：
  docker start redis
停止：
  docker stop -t 60 redis
重启：
  docker restart -t 60 redis
检查运行及健康状态：
  docker inspect --format '{{json .State}}' redis
查看最近日志：
  docker logs --tail 100 --timestamps redis
实时跟踪日志（Ctrl+C 只退出日志查看）：
  docker logs -f --tail 100 redis
查看 CPU、内存等资源占用：
  docker stats --no-stream redis
查看端口映射：
  docker port redis
核对数据与配置挂载：
  docker inspect --format '{{json .Mounts}}' redis
核对自动重启策略：
  docker inspect --format '{{json .HostConfig.RestartPolicy}}' redis
