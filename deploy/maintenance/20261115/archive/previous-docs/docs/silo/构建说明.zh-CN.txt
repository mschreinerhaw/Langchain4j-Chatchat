镜像构建与升级说明：silo
实际镜像 ID、digest、挂载与运行命令见同目录启动维护文档。
构建说明：直接使用上游发布的标准镜像，不构建数据库分叉。
拉取更新（不会自动改变正在运行的镜像）：docker pull pgsty/silo:latest
更新前先备份数据、记录新旧 RepoDigest，并通过审核过的同等挂载配置重建。
Silo latest 是可变标签；本次实际 ID 已记录，不运行自动更新 latest 的任务。
备份要求：OpenSearch 使用快照仓库备份索引；Redis 备份 AOF/RDB；Silo 同时备份对象目录及对应对象元数据数据库。
不要删除这些挂载或执行卷清理。
