# 容器默认参数与生命周期操作

目标平台已通过原有升级页面更新到 **1.1.4**：`http://192.168.195.221:19240`。Runtime OS 仍为 **1.3**，本次没有修改业务镜像或重新部署业务组件。

## 页面入口

1. **镜像管理 → 本地镜像 → 默认启动参数**：查看镜像实际的 ENTRYPOINT、CMD、用户、工作目录、环境变量、声明端口、持久化目录和健康检查。修改下方平台创建模板，经预览、输入目标镜像 ID 确认后保存到 H2。
2. **容器管理 → 创建容器**：选中镜像后自动加载其保存的模板。可以覆盖命令、入口、用户、工作目录、环境变量、端口、CPU、内存、网络和重启策略，再明确选择持久化卷。先确认创建，再确认启动。
3. **容器列表 / 应用组件列表 / 容器详情**：直接显示启动、停止、重启按钮。根据当前状态、账号及资源归属启用；不可用时显示原因。应用接管组件现在能正确识别，不再因为缺少旧版管理标签而隐藏按钮。
4. **容器详情 → 当前生效的启动参数**：查看真实配置、端口和数据卷。下方可以修改当前容器的 CPU、内存与重启策略；每次变更都需要预览及输入目标容器名称确认。保留原有启动时间、重启次数、资源指标及日志展示。

## 生效范围

镜像本身不可变。平台模板按主机和不可变镜像 ID 保存，供**独立创建容器**时使用，修改模板不会修改现有容器。Runtime OS 编排组件继续使用其签名安装协议；本页模板不覆盖 Runtime OS 协议。

CPU、内存及重启策略调整直接调用当前容器的 Docker update 接口，不自动重建或重启。CMD、环境变量、入口、端口和挂载属于创建参数，已有应用需要经配置 / 升级工作流重新部署。手动调整单个应用组件的资源不会改写其签名协议，后续重新部署以协议为准。

密码和令牌不明文回显。已保存秘密显示为 `[REDACTED]`，原样保留该占位符可在后端安全继承原值；不存在对应原值时必须重新输入，不能把占位符当成密码保存。

启动、停止、重启仅作用于确认的当前容器，不级联停止其他服务。共享容器网络命名空间的依赖会在预览时阻止不安全的单独操作，需使用应用流程。外部生产容器、平台控制面和安装任务仍受保护。应用组件不能单独删除；独立容器删除也必须先停止，且不会删除数据卷。

审批绑定目标状态和模板版本，过期或目标变化后需重新预览。变更经既有任务与审计流程记录。
