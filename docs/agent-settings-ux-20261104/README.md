# Agent 设置的说明和高级配置入口

“工具调用设置（高级）”改为“工具调用规则”折叠行，使用 13px 标题、
11px 高级标记和方向箭头。默认折叠时约 35px 高，不再使用大面积卡片。
保留原来的执行顺序、依赖、确认节点和预算等配置，支持键盘展开。

“数据资源授权”改为“可查阅的资料”，说明资料用于查找依据、补充信息和引用来源。
“企业知识文档”选项改为“从知识文档中查找答案”；“资源使用策略”改为
“何时查阅资料”，两个选项分别说明自动按需查阅和用户明确要求时查阅。
下方“知识文档”改为“可查阅的文档”，给出制度、业务规则、需求说明、数据字典等例子。
补充说明启用检索与选择具体文档的关系，仍按使用者权限查阅。

避免本地主源码缺失线上已有功能；仅新增原服务器已有的 17 行 JS、
资源选择模板和相应 API 封装，再作本次文案改动。未改变授权或保存规则。

前端 18 项相关测试、75 个 Vue 组件结构检查通过。

验证标题和说明、折叠高度、键盘展开与收起、复选框大小及表单值保留。
