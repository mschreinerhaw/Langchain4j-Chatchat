# 行情分析 Skill 修订与固定证据评测

## 本轮职责与修改

本轮处理模型计算、比较与解释质量。Runtime 提供授权材料和执行能力，记录执行事实；不以新规则代替模型判断投资结论。已验证的取数链路不因每次文稿错误重新检查，但也不把 Runtime 绝对无误作为前提。

线上原始任务为 `24c6c170-3d10-41a3-abec-0081c82ef2bd`，运行 `att-1-b2637351-15f8-425a-b033-d2e0f0c85791`。报告错误可以直接从其自身文本确认：以约 9.40 元为基数到 15.13 元，涨幅约 60.96%、价格约为原来的 1.61 倍，不是翻倍；不同最新交易日混用；缺少盘口和资金证据却确认资金身份、交易意图与承接深度；将部分题材进展及高 PE 扩大成整体基本面结论。

原任务实际加载的领域 Skill 是「A股投资机会挖掘与选股」，ID `7704e35b-f526-48d4-819d-8b465ac4731e`。本轮通过既有内容接口把 `database/skills/market-analysis-review.md` 补入该 Skill 正文，保留原名称、分类、描述、发布状态、执行配置、编译协议与权限。更新前备份并核对无并发修改，保存后逐字验证正文，状态仍为 PUBLISHED，publicationDirty=false。现有 Skill resolver 直接读取当前正文并据正文生成版本指纹，因此不需要重新编译执行协议或重启服务。

方法包括关键计算的原值、公式、单位和起止日期；共同日期与区间比较；复权、PE、成交口径核对；观测事实、计算和推断分离；证据与措辞强度匹配；由模型在交付前复核算术、日期和正文/局限的一致性。没有新增股票名称分支、行情判决规则、Runtime 报告拦截或通用系统提示词。

## 固定材料与对比设计

冻结原任务授权工具回执，保留该回执 records 中全部 57 条行情与公告记录的价格、日期、单位、来源、公告正文等字段，去除重复 payload 与获取配置。两个模型与两个指导组读取完全相同的投影。原始回执及投影都保留，未重新查询行情。

原始回执文件 SHA256：`fcdc5b246f138a089e908e4b77f4454c0ccaeacd2245d9960767628e111ce407`。
投影 fixture 文件 SHA256：`a99c231f48e2a92c7acd73ef380c3c18ea4bcf314e0f7b06a726dc2aa9c04ca8`。
新增指导组 Markdown SHA256：`25912ade2d7e7d6b7bceacde567350a41909d2b59f2be60e5614d833fc6d7065`。

授权快照中九阳的区间起点可取 9 月 18 日 9.43 元，至 10 月 9 日 15.13 元上涨约 60.45%；这与报告采用近似基数 9.40 元得到约 60.96% 是不同计算口径，不能把正确使用其他明确日期的计算判错。本轮复核依照每份输出实际列出的原值和日期。

原任务问题保持一致；共享系统消息只规定固定材料边界及统一输出长度。baseline 使用原 Skill 正文，guided 使用原正文加新增方法。qwen3.8-max 与 qwen3.7-plus 各对每组生成三次，共 12 份成功输出，终止原因均为 STOP。调用通过已有发布模型表与模型工厂，数据库仅只读，未改变平台默认模型。无工具可调用，无新增外部行情材料。

曾尝试 deepseek-v4-pro，六次生成均因接口余额不足失败；另一次只用于确认接口错误。它们保留为调用失败，不计入质量样本，也不能据此评价模型能力。

这不是完整 Harness 重放：固定投影材料一次性交给模型，不复刻原任务分页读取、工作区或多轮上下文。新增方法增加了提示长度；采样使用既有模型工厂默认值，模型随机性仍存在。此次只包含一个任务的重复生成，不能宣称 12 个独立业务案例或统计可靠的普遍改善。

## 输出审阅结果

下面是逐份输出的探索性审阅，不是已完成双评审的正式盲测。

| 可直接观察的检查项 | 原指导，6 份 | 新指导，6 份 |
| --- | --- | --- |
| 至少一项区间计算明确给出公式/计算关系、原值和日期 | 0 | 4 |
| 明确提醒三股最新快照日期不同 | 3 | 4 |
| 再次出现原报告的“价格翻倍”错误 | 0 | 0 |

公式呈现改善分别为 qwen3.8-max 的 0/3 → 2/3、qwen3.7-plus 的 0/3 → 2/3。新指导其他两份仍只写结果，没有给出完整计算关系。日期不一致提醒分别为 qwen3.8-max 的 3/3 → 3/3、qwen3.7-plus 的 0/3 → 1/3。该项仅统计明确提醒，不代表实际比较、日期或其他指标口径全部正确。

旧指导生成没有稳定复现“翻倍”错误，因此不能声称新指导已经降低该错误率。qwen3.7-plus 原指导三份都保留了较强的资金身份、派发或基本面断言；新指导更常披露缺少资金证据，但仍不稳定。未把这种措辞变化直接换算为整体质量胜率。

仍可核验的问题包括：

- qwen3.8-max guided-2 一面声明不能作严格同日强弱排名，一面把九阳标题写成“短线动量最强”。这是正文与限制的冲突。
- qwen3.8-max guided-3 虽采用共同日期比较，仍将上涨写成主要由题材/情绪推动，并对三只股票作广泛基本面判断；缺少相应因果论证和雪龙公告材料。
- qwen3.8-max guided-1 的 `13.45 / 15.38 - 1` 约为 -12.5488%，按一位小数通常为 -12.5%，正文写 -12.6%，仍存在轻微舍入不一致。
- qwen3.7-plus guided-2/3 仍有确定性的题材驱动和业务未落地推论；guided-3 写“公告均提示”，但同时承认材料没有雪龙专项公告，范围不一致。
- qwen3.7-plus guided-1 虽列出自查段落，仍把投影中未明确标注口径的行情 PE 98.12 称为静态 PE，且五个日涨幅的日期/数值对应不准确。自查声明不能当作正确性证明。
- qwen3.8-max baseline-1 根据采集时间 10:42 推测未收盘，却未处理字段中的 `+00:00` 时区。采集时间不等同于交易时点，日期核对仍是必要的方法要求。

当前观察支持：方法能改善公式呈现和部分证据边界表达；尚不能证明消除了算术、日期、因果或口径错误。模型选择也影响遵循程度，但这个样本不足以给出普遍模型优劣排名。进一步比较应增加未参与指导编写的案例，分别覆盖涨幅/倍数、成交单位、时区、复权、不同截止日、缺失资金证据和不完整公告，再做独立评审。
