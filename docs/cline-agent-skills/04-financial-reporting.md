# 页面文案与金融图报表规范

2026-10-31，按用户要求移除领域技能页中“以下技能由 Coding Agent 镜像提供……”整段说明。远程真实浏览器确认该文字不存在，技能卡片仍正常显示，无页面错误。

金融图报表要求同时进入系统统一 `VisualReportMode` 生成指令和镜像内置 `python-data-analysis` 技能，覆盖静态及交互图。分析技能当前版本为 1.3.0，包含按需读取的 `references/financial-reporting.md`；代码开发技能仍为 1.0.0。

规范包括：

- 已声明的币种、金额单位/缩放、精度，以及百分比、百分点和基点的区分；不猜测缺失的量纲。
- 实际报告期间、估值/交易/交收日期及可比范围；缺失时期不补零，不混合币种或不一致口径。
- 盈亏和差额的零基线、负值与符号；披露局部折线坐标范围，避免误导的双轴、3D及装饰。
- 明确市场配色约定；内地价格/收益通常红涨绿跌，其他市场可不同；颜色之外同时使用符号和标签。
- 资金流与收益、委托与成交、已实现与未实现盈亏分开；勾稽状态由实际计算决定，不把差额硬编码为零或直接等同于数据错误。
- 克制的研报视觉、中文字体、清晰图例与来源，保留既有权限、证据及 INPUT_REQUIRED/UNCONFIRMED 约束。

## 实际生成与复核

通过现有探索工作区及真实 `qwen3.7-plus`/Python Sandbox，以明确标记的合成金融 CSV 验证。5 行样本包含正盈亏、负盈亏、零值和资金流入/流出，字段含义、日期、人民币单位及勾稽口径由验收输入明确声明，不作为真实客户结论。

实际 Cline 自主选中内置分析技能并读取正文及金融参考文档，5 次模型调用、1 次 Python 执行后生成 1 张双面板 PNG 和 2 张 Plotly 图。独立 BigInt 分单位复算确认盈亏合计 8,000 元、净流入 2,000 元、资产变动 10,000 元；每日及全期残差均为 0。归档值与独立结果一致。

浏览器实际加载 PNG，确认红正绿负灰零、正负标签、人民币单位、交易日期、零线及资产折线局部范围说明清晰。历史恢复未触发再次执行，浏览器无错误。Java 业务认证状态仍为 INCONCLUSIVE；合成算术通过不代表对真实客户金融业务的独立认证。

证据：[独立复核](financial-reporting-live.json)、[真实技能调用](financial-sample-journal.json)、[浏览器](financial-browser.json)、[生成图示](financial-preview.png)、[镜像验证](final-worker-verification.json)。
