# 数据探索输入区与提问灵感改进

2026-10-31，分支 `feature/exploration-composer-ideas`。

## 页面行为

- 图表页签、标题、放大窗口及图表辅助标题将 Plotly 技术标记展示为“动态”。这是展示转换；原始报告、图表 kind、序列、单位和历史记录保留。
- Agent 选择移到输入框外下方，采用带图标和箭头的轻量选择栏。正文独占输入区，桌面最低 66px，可随内容增长至上限后滚动。
- 未选 Agent 时仍可输入、打开提问灵感；发送必须匹配当前可用的已发布 Agent。更换 Agent 开始新的分析时保留已输入草稿，保留旧分析结果。
- 框内黄色灯泡提供变化趋势、结构占比、异常/勾稽和问题完善四类建议。根据当前草稿、Agent 名称和已有分析上下文本地组合，不额外读取业务数据或调用模型。建议保留原草稿，点选仅填入文本，用户确认发送后才开始分析；超长时提示精简，不截断原问题。
- 提问面板支持关闭按钮和 Escape；切换分析或 Agent 时关闭旧建议。窄屏自动收起思维链，避免遮住输入框，选中分析节点后也收起浮层。

使用真实已授权的合成金融历史报告进行浏览器验收，覆盖 1588×868 桌面、390×844 窄屏：

- 动态图表实际渲染，页面技术标记替换，数据内容保留。
- Agent 选择在输入框下方，输入区与提问面板位于视口内，窄屏无横向溢出或思维链遮挡。
- 点选建议、切换 Agent 保留草稿；无分析创建、执行或保存请求，零页面错误。
- 普通工作空间导航的偏好保存请求与分析执行分开记录；不将它们误报为分析调用。
