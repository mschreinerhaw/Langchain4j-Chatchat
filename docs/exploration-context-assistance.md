# 数据探索：动态提问建议与补充资料

“灵感”按钮按当前问题草稿、当前节点的已保存结果和用户补充的资料调用模型生成建议，替代输入框中的固定问题模板。服务端从当前用户所属项目加载节点、摘要和表格预览；客户端不能用自填结果替代这些上下文。使用选中且已授权 Agent 的模型配置，未选择 Agent 时使用系统默认模型。

一次生成只调用一次模型，不带工具、不查询外部业务数据、不提交分析任务，也不改写分析项目。建议必须由用户选择、编辑和发送后才进入分析。支持生成状态、重试和换一组；切换节点、修改草稿、切换 Agent 或补充文件后，忽略仍在返回的旧建议。模型失败时显示错误，不回退到固定模板。

输入框提供选择文件、拖拽和粘贴文件，普通文本可直接粘贴。选择模型建议时保留已有问题和粘贴原文，再追加分析问题，避免补充数据被覆盖。上传失败支持重试及移除；每次最多 8 个附件，总计 16 MiB。超过 8,000 字的输入保存为完整 Markdown 附件，保留原始文本，不截断后发送。兼容系统当前的 HTTP 访问方式。

补充资料由服务器按用户、租户校验归属和可用状态。准备追问节点时合并父节点附件与新附件，再交给现有 Agent 文件分析流程的 `__userAssetIds`，由既有需求分析机制决定是否需要业务工具。保留原始文件、受控 Python 分析及图文报告链路。失败或资料不足的节点保持原样，用户补充资料后可以发起新的根节点分析；成功节点仍可继续追问。

进入数据探索时默认折叠系统导航，为思维链、图表和输入框留出空间；用户仍可手动展开。工作空间及 Agent 的角色授权继续有效。
