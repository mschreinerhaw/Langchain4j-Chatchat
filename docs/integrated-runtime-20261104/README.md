# 主分支整合构建与重新部署

将主分支已有的 Studio 历史会话、数据探索工作空间、SQL 元数据及 TDH 修复，
与服务器 R12 发布包中尚未入库的知识探索源码整合，保留本次任务分页授权隔离、
Agent 设置的条件展开、灰色小字和紧凑高级配置。响应过滤器已进入常规 Maven 源码。

从独立工作目录重新编译全部 Java 模块和两个前端，生成完整 API、MCP、News JAR，
并编译 Worker。重新部署使用完整构建产物，不再在旧 JAR 中追加单个页面或类。
所有新镜像通过 org.opencontainers.image.revision 标记同一个整合提交。

本地验证：前端七个套件共执行 744 项检查（含套件间重复），后端专项回归 223 项，
Worker 170 项全部通过，两个前端与 Maven 完整打包成功。
新增知识引用组件和配置展开测试已进入常规前端测试命令；修复测试夹具在 Windows
检出时的换行差异，并保持精确源码修复锚点的校验规则。

部署准备与回滚沿用已经运行验证过的发布流程。发布前核对运行包哈希、运行中任务、
Worker 会话和挂载路径，备份 API/MCP 数据库、配置和原容器；不新增数据库迁移。
先准备所有镜像，再按依赖顺序更换服务、重绑 node proxy 并检查工具注册目录。

source-artifacts.json 记录构建产物及关键类的哈希；deployment.json 记录实际替换的
容器、镜像和提交号。verification.json 与截图记录实际服务器上的功能验证。
