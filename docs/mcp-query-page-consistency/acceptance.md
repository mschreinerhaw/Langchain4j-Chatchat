# MCP 关系库查询页面统一

关系库查询列表和详情统一使用现有 Element Plus、CrudCatalog 和 ModalPanel 组件。SQL Studio 发布模板与手工模板共用同一个详情弹窗，不再分别展示大段技术发布记录和原始元数据结果。

## 页面调整

- 去掉重复的页面标题说明卡片。
- 列表保留模板名称、业务分类、来源、数据源和中文状态；原工具标识、参数摘要、版本等移入详情，减少横向拥挤。
- 两类模板统一提供「详情」，默认展示描述、分类、状态、数据源和来源。已发布模板额外展示格式化时间和版本。
- SQL、参数、编号、元数据及发布历史收进默认关闭的折叠区。权限说明也默认折叠，原有内容和访问限制保留。
- 技术区使用灰色 12px 文字和浅色代码块，避免大标题、黑色代码块和技术编号占据主要页面。
- 每次打开详情均重置折叠状态。手工模板的编辑、测试、停启用和删除入口保持原有行为；SQL Studio 模板沿用原有只读边界。
- 数据源优先展示业务名称，隐藏数据库类型、查询语言及内部编码组成的长标签。
- 手工模板先打开基本详情，仅在展开技术记录后读取元数据；读取失败时在折叠区提供重试，基本详情始终可用。

本次仅修改前端展示，没有修改查询、发布或权限实现。源码提交：`751bbc4a5`、`3e952a44b`。
