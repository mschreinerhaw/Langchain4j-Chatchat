# MCP 工具发布操作路径

## 管理员维护能力

在 MCP 管理端维护 API、查询或资产执行模板。API 页面提供独立的“新建 API 模板”入口、分类目录和分页列表。配置参数、测试接口并启用模板。启用模板表示能力可供授权，不代表某个 Agent 已获得调用权限。

MCP 管理端通过构建环境变量 `VITE_WORKSPACE_URL` 配置统一工作空间地址（不含 hash 路由，支持部署在子路径）。配置后，顶栏提供“前往 MCP 工具发布”链接；未配置时不猜测端口或目标地址。链接不代替目标工作空间登录和权限校验。

## 用户创建、发布和使用

1. 进入统一工作空间的 MCP 工具发布，默认查看“我的发布 / 运行中”。
2. 点击“新建 MCP 工具”，从获准使用的业务模板中选择。可以按分类和关键词筛选，每页显示 12、24 或 48 项。
3. 点击“发布模板工具”，确认模板、分类与关联资源。发布固定模板版本；同一版本重复发布保持幂等。当前版本已发布的模板直接提供“分配给 Agent”。
4. 点击运行中工具的“分配给 Agent”，选择目标 Agent 并勾选工具。进入 Agent 工作空间提出业务问题。
5. 源模板变更后重新确认发布；旧版本可在“已下线”状态下查看。下线和解绑仍使用已有后端授权链路即时限制后续调用。

## 历史版本

仅权限管理员可进入“历史版本管理”。按能力分类和状态筛选、分页查看；“待完成发布”合并草稿、已校验和测试通过的版本，详情提示当前下一步。既有校验、合约测试和正式发布检查保持生效。

分类与说明来自发布快照，源模板撤销或目录权限变化后，历史记录仍保留发布时的业务分类。没有分类的记录显示“未分类”。分类筛选和搜索先于分页，筛选变化回到第一页。

当前目录接口仍返回授权范围内的完整列表，前端对结果分页；本次未将列表接口改为数据库分页。
