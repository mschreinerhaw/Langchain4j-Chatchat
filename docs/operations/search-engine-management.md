# 检索引擎维护与模型选择

## 维护引擎

在“平台管理 → 模型管理”右上角点击“检索引擎”，或在模型编辑窗口的“联网搜索”区域点击“维护检索引擎”。维护入口与模型选项共用数据库中的同一份引擎配置。

点击“新增引擎”，填写：

| 字段 | 用途 |
|---|---|
| 名称 | 模型勾选和维护列表中显示的名称，可自定义 |
| 接口协议 | 当前适配 Tavily、Brave Search、腾讯 WSA；同一协议可维护多个实例 |
| URL | 实际搜索 API 的 HTTPS 公网地址，可编辑；填写 API 地址而非网页首页 |
| API Key | 对应服务的访问密钥，腾讯填写 Secret Key |
| Secret ID | 仅腾讯 WSA 需要 |
| 启用此检索引擎 | 启用且已配置凭据后，进入模型的可选列表 |
| 调用限制 | 可展开维护超时、每分钟、单任务及每日调用上限 |

保存后，名称和 URL 可重新读取；密钥加密保存在服务端，页面不回显。编辑时密钥留空保留原值，输入新值替换；腾讯的 Secret ID 和 Key 可以分别更新。关闭维护窗口会清空密钥输入。

引擎是可新增、编辑、停用和删除的数据，不是系统启动时自动生成的固定选项。删除会清除凭据、撤销该实例的后续调用并保留必要版本及审计；不会因重启而重新出现。需要修改接口协议时，新增对应协议的实例后重新选择。

## 模型多选

编辑一个聊天模型，在“联网搜索”区域：

1. 勾选“联网搜索”。
2. 从已维护、已配置且启用的检索引擎中勾选一项或多项，最多 16 项。
3. 点击“保存模型”。联网能力和选择立即生效；模型本身的草稿/发布流程保持原规则。

每个模型独立保存选择。旧版本的单引擎配置会自动读取为一个选项。若已选实例被停用或删除，页面会显示可取消的失效选项；重新开启搜索前应移除失效项或恢复引擎配置。

Cline 可以在所选引擎内自主指定 `provider_id`，未指定时使用首个选项。工具定义只包含允许使用的引擎 ID 和名称，不包含 URL 或密钥。修改引擎配置、模型选项或关闭搜索会使旧任务的联网授权失效；需要开始新任务使用新配置。

开启联网搜索仍需满足 Agent 与用户的数据资源授权。搜索服务端负责联网，Cline Shell 和 Python Sandbox 的网络出口权限不随模型开关扩大。
