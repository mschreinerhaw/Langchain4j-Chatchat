# 数据探索与智策灵感建议：排查、等待状态修复与部署验证

部署地址：http://192.168.195.221:18100 。验证日期：2026-11-03。

## 现场观察

使用用户提供的管理员账号，通过真实浏览器点击两个页面的小灯泡。部署前，两个页面均发出了 POST 请求并返回真实模型建议，后端也记录了输入、输出 Token 数；本次没有复现“完全没有发送后端模型请求”。智策一次请求约 21 秒，数据探索一次约 26 秒。在模型返回前，原界面持续显示“正在结合当前情况生成提问建议”，前端没有独立的超时处理。

因此，本次修复针对已确认的长时间等待反馈和请求生命周期问题，不将未复现的“请求未发出”作为已确认根因。

## 变更

- 两个页面共用的 PromptComposer 增加 50 秒等待上限，超时后结束加载、显示可重试错误，重新生成使用新的请求。
- 关闭面板、修改草稿、切换上下文或卸载组件时取消浏览器请求；通过序号隔离旧响应，避免旧建议覆盖新输入。
- 取消信号传递到智策接口及数据探索接口；数据探索请求明确携带发起时的工作空间上下文。
- 加载提示说明已请求模型。建议提示词要求简短，保留真实模型生成及用户确认后发送的流程。
- 后端增加生成开始、完成、失败和超时日志，使用 generationId 关联耗时与 Token 用量。原有单次模型调用 45 秒上限保留，超时映射为可操作的 504 错误。取消浏览器请求不等于供应商已停止计算。

## 验证

前端 85 项测试通过，覆盖挂起请求超时后重试、取消信号、旧响应隔离、附件、两个页面的请求及草稿行为。后端 11 项定向测试通过，覆盖授权、上下文、真实模型调用边界、无效输出，以及模型超时后释放并发槽位供重试。前端生产构建和 git diff --check 通过。

线上浏览器验证脚本为 `scripts/verify-question-ideas-live.mjs`，凭据通过环境变量注入。两个页面分别执行首次生成和换一组，共 4 次请求，每次返回 3 条模型建议；每次点击对应一次后端请求。选择建议保留原草稿，建议仍可编辑，没有提交聊天或分析任务，浏览器未记录页面异常。

最终四次响应耗时依次为：智策 21,564 / 22,438 毫秒，数据探索 41,719 / 31,430 毫秒。模型延迟仍然存在，本次没有承诺即时生成。
