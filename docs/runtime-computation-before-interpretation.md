# 计算前置与确定性归并

本轮替换原有“Worker 写分析、Reducer 再调用模型总结”的执行行为，保留现有任务隔离、检查点和证据谱系接口。

执行顺序：

1. 投影数据并解析明确声明的数据集关系。
2. 进入统一问题分析图，在计算节点解析计算契约、执行确定性计算。没有可用契约时记录具体原因，不猜测字段含义或计算公式。
3. 按输入预算将数据集原文或全量画像、已有计算的有界视图传给全局 Findings 节点。模型可以定向读取原始记录或已有计算结果，最多三轮。保留数据集边界，不授权隐式跨数据集关联。外层不按数据集派发模型报告任务。
4. Java 检查结构化输出和每项结论的证据。协议无效或引用未知数据集时明确失败；语义不支持的结论沿用现有治理规则处理。外层不再启动逐数据集模型修复。
5. 数据集和关系组归并不再调用模型，不生成新的派生结论；保留上游证据、关系和谱系，去除完全相同的重复叙述。
6. 已通过验收的预计算结果进入现有最终结论与报告编排链路，不再次计算。

同时统一 Worker 提示词与校验字段：`outputUnit`、`grain`、`timeScope`、`populationScope`、`alternativeExplanations`，置信度明确为 `HIGH/MEDIUM/LOW`。

外层任务扇出已替换为统一问题图，并接入 [有界证据执行](runtime-bounded-analysis-evidence.md)。尚未完成的目标包括模型驱动的新计算计划、流式数据读取、长文本的分片语义提取、最终报告覆盖度硬验收、支撑明细与图表的完整发布联调。本轮不代表这些能力已经实现，也不提供未经实际运行测量的提速比例。
