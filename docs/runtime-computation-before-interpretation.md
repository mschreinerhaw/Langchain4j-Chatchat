# 计算前置与确定性归并

本轮替换原有“Worker 写分析、Reducer 再调用模型总结”的执行行为，保留现有任务隔离、检查点和证据谱系接口。

执行顺序：

1. 投影数据并解析明确声明的数据集关系。
2. 在派发模型任务之前解析计算契约、执行确定性计算。没有可用契约时记录具体原因，不猜测字段含义或计算公式。
3. 将已验证计算结果、计算决策和全局已返回数据集目录传给解释任务。目录仅用于识别已有数据，不授权跨数据集关联。
4. 检查结构化输出。无效洞察触发一次带校验决策的修复，重用原记录。修复失败保留原产物，候选结果不得删除原先已通过的洞察。
5. 数据集和关系组归并不再调用模型，不生成新的派生结论；保留上游证据、关系和谱系，去除完全相同的重复叙述。
6. 已通过验收的预计算结果进入现有最终结论与报告编排链路，不再次计算。

同时统一 Worker 提示词与校验字段：`outputUnit`、`grain`、`timeScope`、`populationScope`、`alternativeExplanations`，置信度明确为 `HIGH/MEDIUM/LOW`。

尚未完成的架构目标：按分析问题而非数据集规划全部任务、由解释结果请求新的计算并循环执行、最终报告覆盖度硬验收、支撑明细与图表的完整发布联调。本轮不代表这些能力已经实现，也不提供未经实际运行测量的提速比例。
