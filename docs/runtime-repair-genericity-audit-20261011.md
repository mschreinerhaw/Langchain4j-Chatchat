# 本轮 Runtime 修复的业务硬编码审查

审查范围：当前工作区探索进度、探索图、报告 JSON 展示、外部搜索补充、MCP 原生数据库客户端的改动，以及新增 NativeDatabaseClient / NativeClientPool。审查结合 Git 差异、生产源码关键词扫描和分支阅读；不是对整个仓库历史实现的无业务耦合认证。

## 结论

本轮生产逻辑未发现按顶点软件、603383、融资问题、行情日期、具体价格、指定任务 ID、指定数据集或生产 IP 触发的修复分支。原始股票案例仅在展示回归测试和历史排查文档中保留。

| 修复 | 决策依据 | 是否替模型制定业务分析 |
| --- | --- | --- |
| 探索进度 | 模型轮次、实际取证请求与回执状态 | 否；可选公开摘要，不要求领域分析步骤 |
| 探索图更新 | 上下文指纹、请求 ID / 索引 | 否；投影事实，不从事件邻接推断因果 |
| 探索图去开关 | 用户明确指定的统一展示行为 | 否；不按任务内容切换 |
| 报告 JSON 展示 | 声明字段、协议版本、Runtime 校验状态、已注册渲染器 | 否；不查业务关键词，不猜测或补造数据 |
| 外部搜索补充 | 调用方显式 external_search_required 参数 | 否；不根据“股票”“融资”等词自动切换路由 |
| 原生客户端 | 数据源资产类型、连接配置、凭据和超时 | 否；客户端分支属于技术适配，不依赖业务表/字段 |
| TLS 兼容 | 操作者已有配置中的 URL 和 insecureSsl | 否；无固定生产 IP，匹配配置端点且保留明确设置 |

## 本次收紧

- 报告解析器从共享 visualization-capabilities.json 对应模块读取已注册渲染类型、maxBlocks、maxRows，删除重复维护的类型列表及 6 / 120 常量。
- 新增 external_search_required 参数说明改为 local evidence，避免用金融数据描述通用补充检索控制。
- 在保留原始故障样例之外，补充库存、服务延迟、实验结果、自定义未知渲染类型的参数化回归。不同业务标识与数据集均按同一协议生成摘要，不生成不存在的实际数据。

协议字段名、客户端类型、运行事件枚举及容量/超时保护属于技术契约；它们不决定分析对象、指标或结论。报告摘要只展示模型已提供的标题、结论和原因。

## 范围边界

RemoteNewsMcpToolProvider 原有金融数据资产发现和 DynamicDateParamService 原有交易日历仍是领域工具能力，当前修复没有把这些能力植入 Harness 或要求所有分析必须调用它们。此次审查不宣称这些历史工具已经领域无关，也不擅自更改其已有业务契约。

## 验证与部署

本次 6 个前端测试文件共 58 项通过，包含原始股票样例及 4 个不同领域/自定义声明用例。前端生产构建验证通过。本次收紧尚未部署生产；此前已部署的客户端和进度修复没有新增业务专用分支。
