# Agent 数据资源配置

在现有权限控制台为用户或角色授予逻辑数据资源 `DATA_RESOURCE/financial_news`、`DATA_RESOURCE/financial_market`。文档继续使用已有知识/文档授权及 Agent 文档绑定。资源默认不开放；Agent 页面勾选资源不会给用户增权。管理账号仍需原有 Agent 工作台权限。

在 Agent 工作台选择企业知识文档、新闻资讯、金融市场数据，保存后重新打开确认。企业知识还需选择具体文档。资源策略为“按任务需要”或“仅本次明确要求”；后者需要用户在提问入口勾选本次使用已授权资料，提交后该选择重置。复用现有 Agent 版本快照与审计。

运行时权限取当前用户、Agent 配置及任务工具白名单交集。Cline 仅获得逻辑工具及证据 ID，不获得管理员凭据、索引名称、任意 DSL 或 SQL。文档提供搜索、元数据、章节、片段及关联候选；新闻提供检索、原文片段及关联候选；金融提供目录发现、历史、已采集指标及最新可用快照。

新闻和金融读取通过已有 MCP 控制面及 News Runtime；MCP 入口归属现有 `newsCollection` License 模块，与原新闻检索、金融查询相同，仍需有效许可证。不得通过关闭 License、放开未登记路由或给模型管理员令牌解决访问问题。

引用打开时重新授权并重新读取当前来源；撤权、来源更新或删除使旧结果不可读，需重新发起任务。历史使用过来源的会话不将旧资料直接交给后续普通分析任务。此行为是服务端访问治理，无法撤回用户此前已经看到或自行保存的内容。

金融目录不是行情明细。应先发现数据集与字段，再读取现有 FinancialDataStore；保留日期、来源、单位、复权口径和许可属性。`realtime:false` 的快照不可当作实时行情。新闻发布时间与采集时间分别展示；没有正文、完整历史或准确证券关联时明确说明。行业筛选是文本匹配，不是已治理行业分类。

金融目录的 `last_collected_at` 是数据集采集心跳，不等于查询结果中每条行情的采集时间。引用保留探索时看到的目录心跳，并单独展示实际记录声明的采集时间与数据截止日；仅心跳推进不会使未变化的历史行情失效。记录值、记录采集时间、目录口径、文档正文、新闻内容及权限仍重新校验。缺少实际记录采集时间时显示未知，不用目录心跳替代。

没有证据支持的结论必须保留未知；设计恢复方案不等于实际演练通过，新闻相关性不等于价格变化因果。原生 Skills 按任务资源范围出现，并由 `skill_read` 读取正文；其他 Coding Agent 不常驻加载这些资源技能。
