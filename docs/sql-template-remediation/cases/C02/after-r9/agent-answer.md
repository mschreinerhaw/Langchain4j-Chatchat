## 五、口径、限制与说明

1. 查询实际生效参数：仓库 2、1998-01-01 至 1998-01-29（含端点）、数量下限 0、类别不限，与需求一致。
2. 逐日序列不完整：29 个自然日仅 5 天有快照，缺口 24 天；来源未声明快照生成频率，缺口原因无法判定，报告中不将缺口视为 0，也不插值。
3. 计量单位限制：现存数量合计的单位未由数据源声明，因此未推测为“件”“个”或其他单位，也不与任何金额口径混用。
4. 记录数口径：库存记录数按数据源逐日明细计数（COUNT(*)），不是去重商品/SKU 数量；来源未提供去重商品口径。
5. 类别口径：类别筛选为“不限”，结果未按类别拆分，不能据此给出类别结构结论。
6. 汇总合计的解读：现存数量合计为各快照日的时点存量，跨日期相加没有业务意义，故未提供区间“总合计”，仅给出每日数值及首末时点差。
7. 样本限制：仅 5 个时点，无法据此判断长期库存水平、波动规律或因果。
