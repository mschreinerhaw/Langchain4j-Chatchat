## 口径

计时从 Node 接受任务开始。首次提案、CODE_READY、Python 派发、结果可用、HTTP 完整分别统计；
修复首次新代码不包含复用用户原代码。Provider 未返回的 usage 为未知，合计仅为下界。
preCodeInputTokensKnown 是首提案前已取得的 Provider 输入用量，另列已知用量调用数，不把未知当0。
首提案前模型调用统计 startedAt 不晚于首次提案的调用，因此包括产出该首次提案的那一轮；1次表示可能直接编码，不等于先做了一轮额外准备。
分项 Skill Tokens 仅可作字节估计；上下文占比使用实际最终请求字节，不能分摊整次 Provider 用量当精确计费。

基准和候选为顺序小样本，不能证明因果或稳定p95；全部失败、缺失观测和超时保留。
基准及候选的请求 ID 在发送前持久化，丢失响应不自动重提，不修改预算/推理配置美化耗时。
