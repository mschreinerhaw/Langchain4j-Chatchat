## 任务和交付合同

Java 在授权输入内冻结与 Runtime 最终校验同一份 Schema。首版隔离验证使用只读 Schema 文件，后续版本把 Schema 合并进原生读取治理已授权的数据供应清单。统一启动提示提供分析范围、报告语言、格式、交付目录及原生完成条件。Executor 创建交付目录。报告和 JSON 文件名仍由分析任务选择。中文请求默认使用中文，已有显式语言配置或用户在任务中指定的语言优先。

RESULT 错误使用 JSON Pointer、错误类型和修正要求。必填项错误最多返回八条缺失路径，模型无需再接收整个 Schema 或重生成报告。旧任务可使用已冻结的内联 Schema。结构校验、原生完成回执、产物哈希、Silo 上传和 Runtime 校验继续存在。

模型回执新增任务轮次和执行阶段，Runtime 同时接收上游请求标识。工具观察新增参数及结果摘要和结果字节数。新字段确定主分析或交付修复所属轮次，主分析内部的模型意图仍需通过工具与结果证据分类。
