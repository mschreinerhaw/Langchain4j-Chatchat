### Key Findings

1. **Exact overlap:** The 3 synthetic rows (Jan=112, Feb=118, Mar=132) are
   identical to the first 3 rows of the public series (1949-01/02/03).
2. **Scale:** Synthetic (3 mo) = 2.1% of public (144 mo).
3. **Mean:** Synthetic mean (120.67) < public mean (280.30)
   because only the earliest low-traffic period is sampled.
4. **Units:** Both integer monthly passenger counts.
