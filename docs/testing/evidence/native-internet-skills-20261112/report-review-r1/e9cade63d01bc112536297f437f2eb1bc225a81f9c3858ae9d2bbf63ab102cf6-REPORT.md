# Airline Passenger Data — Independent Review Report

## 1. Scope & Purpose

This report independently re-examines a comparison between a **synthetic local** Parquet file and a **public historical** monthly airline-passenger CSV. The earlier deliverable contained two unsupported claims that are corrected here.

## 2. Unsupported Claims in the Earlier Deliverable — Corrections

| # | Earlier claim | Why it is unsupported |
|---|---|---|
| 1 | "Both integer monthly passenger counts" (identical units) | The public series is described by Box & Jenkins (1976) and multiple authoritative references as monthly totals **in thousands** of international airline passengers. The synthetic Parquet provides no year, unit-scale, or construction-history evidence; its column label "passengers" does not establish a scale. Numerical overlap of the first 3 values does not prove identical units. |
| 2 | "Synthetic mean < public mean because only the earliest low-traffic period is sampled" | The synthetic Parquet contains no year field and no evidence of a sampling process. The month labels (Jan, Feb, Mar) carry no year. Numerical overlap with the first 3 public rows is an observation; it does not establish that the synthetic file was derived by sampling the public series. |

### Public-series units (from external references)

Multiple authoritative sources describe this dataset (Box & Jenkins 1976, R `AirPassengers` documentation, CMICH SPSS workshop, O'Reilly/Packt) as monthly totals of international airline passengers **in thousands**. The CSV column header is simply "Passengers" with integer values; the "in thousands" scale comes from the original publication, not from the file itself. This is reported as established context, not as a guarantee that every downstream copy preserves the same scale.

### Observations (not inferences)

1. **Numerical overlap:** The 3 synthetic rows (Jan=112, Feb=118, Mar=132) have the same integer values as the first 3 rows of the public series (1949-01, 1949-02, 1949-03). This is a factual observation.
2. **Coverage asymmetry:** The synthetic file has 3 rows vs. 144 in the public series (2.1%).
3. **Mean difference:** The synthetic mean (120.67) is less than the public mean (280.30). **Why** this is so cannot be determined from the available evidence — the synthetic file carries no year, no unit scale, and no provenance metadata.

### What cannot be concluded

- That the synthetic file was sampled from or derived from the public series.
- That both files share the same unit of measurement.
- That the mean difference is explained by temporal sampling.
