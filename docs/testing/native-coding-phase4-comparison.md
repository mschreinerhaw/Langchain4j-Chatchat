## 对照资格

按任务书命名：A 为官方 Cline CLI/客户端，**本轮未执行**；B 为原 SDK 参考执行器，保留 Phase 3 的历史 2/8 完整交付、7/8 独立源码通过，存在命令执行器、并发/超时和治理差异，**不得直接归因于模型或作为等价原生 CLI 结果**；C 为 Runtime。本轮对 C 的修复前原第四批及修复后固定样本进行实际回归，不冒充完成了新的 A/B/C 随机交叉试验。

旧第四批证据文件还包含更早批次的投影，比较脚本按 summary 中的**完整 taskId 唯一连接**，不能取文件前八条冒充该批。旧、新逐任务请求 Hash、fixture、harness、模型连接指纹、8192 输出、授权/实际披露及 Schema、原预算限额均逐项相同，见 [对照控制检查](evidence/native-coding-phase4/after-r2/control-checks.json)。仅模型可见事实及缺确认后的重载顺序改变；验收观察入口记录白名单元数据而不改原请求。

## 测量限制与复现

原用量中 CPU、峰值内存及实际成本计量不完整，保留未结算 reservation。报告将这些实际测量记为 null/未测量，不能把原始零字段解释成没有消耗。模型调用为 Runtime 准入数，未独立测量供应商内部重试。端到端 harness 时间包含任务停止后的独立复核，不能直接作为 Agent 耗时；查看模型回执开始/结束时间及归档时间时需保持各自定义。
