# 统一查询参数写法

2026-11-02，关系库查询中的 SQL Studio 来源与手工模板统一使用 `{{参数名}}`，例如 `WHERE warehouse_id = {{warehouse_id}}`，占位符外无需引号。

手工模板打开时将旧 `:参数名` 转为统一显示；离开编辑器、执行和保存时同步规范化。原记录不会被批量改写，旧格式仍可在执行端使用。参数识别不扫描 SQL 注释、普通字符串、带引号标识符及 PostgreSQL dollar-quoted 内容，保留 `::` 类型转换。SQL Studio 原始 SQL 继续只读展示。

服务端在手工查询进入 JDBC 执行前，将 `{{参数名}}` 转为命名绑定，参数值继续单独传递。普通草稿、已保存模板、查询步骤和内置金融数据源均支持相同写法。动态日期处理在绑定语法规范化后执行，保留显式传入的参数值。SQL Studio 继续使用已有的 PreparedStatement 执行通道。
