# 智策空间动态提问灵感

智策输入框在“图文报告”旁显示黄色“灵感”按钮。新对话结合草稿与附件生成建议，历史对话同时使用服务器读取的近期对话内容。建议来自实际模型调用，可重新生成；选择后保留已有问题及粘贴原文，并由用户确认发送。切换对话、修改草稿、调整附件或 Agent 时，旧建议失效。

智策使用 `/api/v1/interactions/ideas`，要求智策空间入口和聊天交互授权；不要求数据探索权限。后端校验同租户、对话归属、附件归属及当前 Agent 授权，不将其他用户对话或 SQL/Python 工作区历史混入上下文。新对话生成建议不创建会话或分析任务。

智策与数据探索共用 `QuestionIdeaService`，复用单次限时模型调用、附件预览、结构化建议验证及失败重试语义。问题方向依据当前业务与 Agent，运维等非金融场景不会被强制改成金融主题。现有数据探索入口仍独立校验其空间授权。

本地针对性检查：后端 27 项、前端 103 项通过，前端生产构建及完整应用打包通过。

- 未授权数据探索的角色可以生成建议，不能进入数据探索。

- 小黄灯位于正常聊天工具栏，选择建议保留草稿，切换新对话关闭旧建议。
- 无聊天或分析任务提交，对话记录不变，无浏览器异常或失败接口请求。
- 外部用户对话、外部附件、未授权 Agent 均被拒绝；撤销智策入口后原会话立即被拒绝。
