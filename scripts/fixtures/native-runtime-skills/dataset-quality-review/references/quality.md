# Quality and interpretation

Describe the observed row grain, types, missing values and duplicate keys. A missing source differs from a verified empty table; a null value differs from zero.

Keep source provenance and measurement units with numerical findings. Synthetic observations and independently obtained public records have different evidential roles, even when their columns look alike.

Retain calculation precision in machine-readable results. Apply presentation rounding separately, and state comparison limits when coverage, units or populations differ.
